New installations now start with **Claude Code on this machine** as the compiler
choice. Warden guides administrators through installation, sign-in, a connection
test and applying the configuration before drafting real rules.

### Compiler setup
- Open **Configure Claude Code** from solo or team mode. Models opens the
  compiler setup automatically when configuration is incomplete.
- See installation, authentication and connection results separately. A found
  executable is no longer presented as proof that the account can answer.
- Leave the model blank to use Claude Code's configured default. Existing
  compiler selections and explicit environment overrides remain intact.
- Test a fixed, synthetic structured response before applying Claude Code.
  Failed checks keep the previous compiler selection. Account details and
  credentials are not returned to the console.
- Initial downloads skip the 1.1 GB local compiler weights when Claude Code is
  selected. The local analyzer and its required models remain unchanged.
- Continue editing compiler and analyzer prompts independently of model setup.
